# LINK Community Hub™ — Linked Page Header Standard

STATUS: LOCKED
LOCKED: August 27, 2026

This is the approved and permanent visual standard for all
LINK Community Hub™ linked public pages and portals.

## REQUIRED STRUCTURE

1. White brand/header strip
2. Approved horizontal LINK Community Hub™ · Lake Norman logo
3. Logo left aligned at the established canonical size
4. Navy navigation bar directly beneath the white header
5. One header only
6. One public navigation bar only
7. Consistent spacing, scale, alignment and responsive behavior

## DO NOT CHANGE

Do not replace the horizontal logo.
Do not use the old square LINK logo.
Do not add a second LINK logo in page heroes.
Do not create floating logo cards.
Do not enlarge the logo beyond the canonical standard.
Do not create page-specific header variants.
Do not create separate portal header systems.
Do not stack CSS overrides that alter this header.
Do not redesign this treatment unless Jaime explicitly unlocks it.
